QUEST 1

冒険者登録をする

クリア条件：Claudeの有料プラン（Pro）に登録する

無料プランでは使えません

ここ、意外と知られていないんですが、Claude Codeは無料プランでは使えません。いちばん安いのが「Pro」というプランです。

年払い年200ドル
（月17ドル相当）		続けると決めたら、こっちのほうが安い

※2026年11月時点の公式ページの金額です。料金は変わることがあるので、登録するときに公式ページで確認してください。

登録の手順

  1. claude.com を開いて、メールアドレスかGoogleアカウントでアカウントを作る
  2. 料金ページ（claude.com/pricing）で「Pro」を選ぶ
  3. 支払い方法を入れて、登録する

QUEST 2

拠点を建てる

クリア条件：Claudeのアプリを入れて、「Code」の画面を開く

黒い画面は使わなくて大丈夫

Claude Codeの解説を見ると、黒い画面（ターミナル）に英語の命令を打ち込むやり方がよく出てきます。あれを見て「無理だ…」ってなった人、大丈夫です。

今は、Claudeのアプリの中にClaude Codeが入っています。アプリを入れて、ボタンを押していくだけで使えます。

必要なもの

  • パソコン（Windows 10以降／Mac）※スマホだけでは使えません
  • インターネット
  • クエスト1で登録したアカウント

アプリを入れる手順

  1. claude.com/download を開いて、自分のパソコン（WindowsかMac）のアプリをダウンロードする
  2. ダウンロードしたファイルを開いて、インストールする
  3. アプリを開いて、クエスト1のアカウントでログインする
  4. 画面の左上にある「Code」をクリックする
パソコンに慣れている人へ（黒い画面で使う方法）

ターミナルを使ったことがある人は、こちらでもOKです。

Mac（ターミナル）

curl -fsSL https://claude.ai/install.sh | bash

Windows（PowerShell）

irm https://claude.ai/install.ps1 | iex

入れたら、新しいウィンドウを開いて claude と打てば起動します。最初の1回だけ、ブラウザでログインします。

QUEST 3

相棒に指示書を渡す

クリア条件：副業用のフォルダを作って、指示書（CLAUDE.md）を置く

Claude Codeは「フォルダ」で覚える

動画で「フォルダにやり方を入れておくと覚えてくれる」とお話ししましたよね。その仕組みが、ここで作るフォルダです。

Claude Codeは、開いたフォルダの中身を読んで仕事をします。そして、フォルダに「CLAUDE.md」という指示書を置いておくと、毎回最初にそれを読んでくれるんです。

つまり、自分のことや書き方のルールを1回書いておけば、毎回説明しなくていい。ここが、毎回一から説明が必要なチャットのAIとの違いです。

手順

  1. パソコンの「ドキュメント」の中に、新しいフォルダを1つ作る（名前は「副業ラボ」など、何でもOK）
  2. アプリのCodeの画面で、入力欄の下にある場所の選び方から「ローカル（Local）」を選ぶ
  3. その横の「フォルダを開く（Open folder）」から、1で作ったフォルダを選ぶ
  4. 下の「はじめの設定」を、【】のところを埋めてから、そのまま入力欄に貼って送る

すると、Claude Codeが3つのフォルダと指示書を自分で作ってくれます。

道具①｜はじめの設定

どうぐ：あいぼうのしじしょ
このフォルダを、私の副業の作業場所にしたいです。
次の2つをやってください。

1. このフォルダの中に「ナレッジ」「投稿ストック」「伸びた投稿」の3つのフォルダを作る
2. このフォルダに CLAUDE.md を作り、下の内容をそのまま書き込む

---ここから CLAUDE.md の内容---
# このフォルダについて
副業（スレッズ×楽天アフィリエイト、コンテンツ販売）の作業場所です。

# 私について
- 副業に使える時間：【例：平日は1日30分、休日は2時間】
- 発信するジャンル：【例：一人暮らし向けのガジェット・便利グッズ】
- 届けたい人：【例：一人暮らしを始めたばかりの20代の会社員】

# 書き方のルール
- 一文は短く。むずかしい言葉は使わない
- 使っていない商品を「使ってよかった」と書かない
- 商品を紹介する投稿には、必ず「#PR」を入れる
- 「絶対」「誰でも」「必ず稼げる」のような言い切りは使わない

# フォルダの使い方
- ナレッジ：参考にするやり方や、伸びている投稿の分析を入れる
- 投稿ストック：作った投稿の下書きを入れる
- 伸びた投稿：実際に伸びた投稿と、その数字を入れる

# 作業のしかた
- 投稿を作るときは、先に「伸びた投稿」と「ナレッジ」を読んで、その傾向をふまえる
- 作業を始める前に、何をするかを短く説明してから進める
---ここまで---

ちゃんと自分の言葉で書いてほしいのですが、書き方の見本として活用してください。

最初は「確認してから進める」モードで

Claude Codeは、ファイルを作ったり書き換えたりする前に「やっていいですか？」と聞いてくれるモードがあります（Manual）。慣れるまでは、このモードのまま使ってください。勝手に何かを消されたりする心配がありません。

道具②｜伸びている投稿を集める

どうぐ：さぐりのまきもの
スレッズで、【一人暮らし向けのガジェットや便利グッズ】の投稿のうち、フォロワー数より表示回数が多い投稿を10個集めて、伸びている理由と一緒に一覧にしてください。
表示回数・フォロワー数・何倍か、と、伸びている理由の共通点もまとめてください。
できた一覧は「ナレッジ」フォルダに保存してください。

うまく集まらないときは、自分でスレッズを見て「これ伸びてるな」と思った投稿の文章を貼って、「この投稿が伸びている理由を分析して、ナレッジに保存して」とお願いすればOKです。

道具③｜投稿を作る

どうぐ：ことのはのまきもの
「ナレッジ」フォルダの一覧でいちばん強かった【質問型】の投稿の流れを使って、楽天市場で売られている【充電器】を紹介する投稿を3パターン作ってください。
本投稿では商品名を出さずに質問して、自分の返信（リプ）で商品を紹介する形にしてください。
その商品のリンクも教えてください。
できた投稿は「投稿ストック」フォルダに保存してください。
